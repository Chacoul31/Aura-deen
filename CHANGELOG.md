📌 Principes de publication

Les modifications importantes doivent être ajoutées à ce fichier lors des nouvelles versions.

Les changements peuvent notamment être classés dans les catégories suivantes :

Added

Nouvelles fonctionnalités.

Changed

Modifications de fonctionnalités existantes.

Improved

Améliorations de performances, d'interface ou d'expérience utilisateur.

Fixed

Corrections de bugs.

Removed

Fonctionnalités supprimées.

Security

Corrections ou améliorations liées à la sécurité.

🌿 Versions futures

Les prochaines versions d'Aura · Deen peuvent introduire des améliorations présentées dans "ROADMAP.md".

La roadmap n'est pas un engagement sur une date de sortie précise et peut évoluer au cours du développement.
