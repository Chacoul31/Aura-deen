## ✨ À propos

**Aura · Deen** est une application web open source conçue pour réunir
dans une même expérience plusieurs ressources permettant de **lire,
écouter, rechercher et découvrir** des contenus islamiques.

Le projet cherche à proposer une interface moderne tout en conservant
une approche simple, locale et respectueuse des sources.

> 🌿 **Une interface moderne. Des sources respectées. Une expérience
> pensée pour l'utilisateur.**

## 🔎 Une recherche pensée pour retrouver le bon contenu

Aura · Deen permet d'explorer les contenus à partir de plusieurs
approches :

-   🔤 mots-clés ;
-   📖 sourate ;
-   🔢 référence ;
-   🏷️ thème ;
-   📚 source.

L'objectif est de **retrouver des contenus existants**, et non de
fabriquer artificiellement des réponses religieuses.

------------------------------------------------------------------------

## 🧠 Une approche différente de l'IA

L'intelligence artificielle peut être utilisée comme technologie pour
certaines fonctions techniques du projet.

Cependant, Aura · Deen suit un principe clair :

> **Les versets, hadiths, invocations et citations religieuses ne
> doivent pas être inventés par une IA et présentés comme des sources
> authentiques.**

Les contenus religieux sont traités comme des données provenant de
sources identifiées.

Pour les questions religieuses importantes, Aura · Deen ne se présente
pas comme une autorité religieuse.

------------------------------------------------------------------------

## 🔒 Privacy First

La confidentialité fait partie des principes du projet.

Lorsque cela est possible :

-   les préférences sont conservées localement ;
-   la progression peut être conservée localement ;
-   certaines statistiques restent sur l'appareil ;
-   aucune création de compte n'est nécessaire pour l'utilisation de
    base.

> **Votre expérience compte plus que la collecte de vos données.**

Certaines ressources ou fonctionnalités externes peuvent néanmoins
nécessiter Internet et être soumises aux conditions de services tiers.
