Code of Conduct

Notre engagement

Nous voulons faire d'Aura · Deen un projet accueillant, respectueux et accessible à tous.

En participant au projet, que ce soit par une contribution, une issue, une pull request, une suggestion ou une discussion, vous acceptez de respecter ce code de conduite.

Comportements attendus

Les contributeurs sont invités à :

- Respecter les autres participants, quelles que soient leurs origines, leurs opinions ou leur niveau d'expérience.
- Communiquer de manière constructive, calme et respectueuse.
- Accepter les critiques et les désaccords de manière professionnelle.
- Donner des retours utiles et argumentés.
- Respecter le travail, le temps et les contributions des autres.
- Signaler les problèmes de manière claire et responsable.
- Faire preuve de prudence et de respect lorsqu'il est question de contenu religieux.

Comportements inacceptables

Ne sont notamment pas acceptés :

- Les insultes, attaques personnelles, humiliations ou menaces.
- Le harcèlement ou l'intimidation.
- Les propos discriminatoires ou haineux.
- La publication d'informations personnelles concernant une autre personne sans son consentement.
- Le spam, le trolling volontaire ou les provocations répétées.
- Toute contribution volontairement malveillante visant à nuire au projet ou à ses utilisateurs.
- La falsification ou la présentation trompeuse de contenus religieux comme provenant de sources authentiques.

Contenu religieux

Aura · Deen traite de contenus religieux qui doivent être abordés avec sérieux et respect.

Les contributeurs doivent, dans la mesure du possible :

- Indiquer clairement les sources des contenus religieux ajoutés.
- Vérifier les références avant de proposer du contenu.
- Éviter de modifier ou de présenter comme authentiques des textes dont l'origine n'est pas vérifiée.
- Signaler les erreurs ou références douteuses lorsqu'elles sont découvertes.
- Éviter de présenter Aura · Deen comme une autorité religieuse.

Les discussions théologiques peuvent donner lieu à des divergences d'interprétation. Ces divergences doivent rester respectueuses et constructives.

Contributions au projet

Toute contribution doit respecter les licences applicables aux fichiers concernés.

Avant d'ajouter du contenu provenant d'une source externe, le contributeur doit vérifier qu'il dispose du droit de le redistribuer et, lorsque cela est nécessaire, fournir les informations relatives à sa licence et à sa source.

La licence MIT du projet ne signifie pas nécessairement que les contenus tiers présents dans le projet sont eux-mêmes placés sous licence MIT.

Modération

Les responsables du projet peuvent supprimer, modifier ou refuser toute contribution qui ne respecte pas ce code de conduite.

Selon la gravité ou la répétition du comportement, des mesures peuvent être prises, notamment :

1. Un avertissement.
2. La suppression d'un contenu problématique.
3. La fermeture d'une issue ou d'une pull request.
4. Une restriction temporaire de participation.
5. Une exclusion du projet.

Les décisions de modération doivent être prises de manière raisonnable et proportionnée.

Signalement

Si vous constatez un comportement contraire à ce code de conduite, veuillez le signaler aux responsables du projet.

Lorsque cela est possible, fournissez :

- Une description claire du problème.
- Le lien vers l'issue, la pull request ou la discussion concernée.
- Les informations permettant de comprendre le contexte.

Les signalements doivent eux-mêmes rester respectueux et ne doivent pas être utilisés pour harceler ou cibler une personne.

Portée

Ce code de conduite s'applique à toutes les interactions liées au projet Aura · Deen, notamment :

- Les issues GitHub.
- Les pull requests.
- Les discussions.
- Les commentaires.
- Les contributions au code ou aux données.
- Les autres espaces officiellement associés au projet.

Mise à jour

Ce code de conduite peut être mis à jour lorsque cela est nécessaire afin d'améliorer la collaboration et la sécurité de la communauté.
